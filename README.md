# ariesworx/.github

Default community health files for Ariesworx repositories. GitHub uses each of
these for any public repository in the organization that does not have its own:

| File | Purpose |
|---|---|
| `CODE_OF_CONDUCT.md` | Contributor Covenant 3.0, reports to conduct@ariesworx.com |
| `CONTRIBUTING.md` | Branch and title prefixes, signed commits, how to propose a change |
| `SECURITY.md` | Private vulnerability reporting and safe harbor |
| `SUPPORT.md` | Where to ask for help |
| `pull_request_template.md` | Before/After, How, Testing, checklist |
| `ISSUE_TEMPLATE/` | Bug and feature forms; blank issues off |

A repository's own copy always wins. LICENSE and Dependabot settings are never
inherited, so each repository keeps its own.

`profile/README.md`, when added, becomes the public page at github.com/ariesworx.
The members-only page lives in `ariesworx/.github-private`.
