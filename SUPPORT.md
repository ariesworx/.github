# Getting help

| You want to… | Go to |
|---|---|
| Report a bug or ask for a feature | The repository's **Issues** tab, using the issue form |
| Ask how to use something | The repository's README first, then open an issue labelled `question` |
| Report a security problem | The repository's **Security** tab → **Report a vulnerability** (never a public issue) |
| Report a Code of Conduct concern | conduct@ariesworx.com |

These are open-source projects maintained by Ariesworx LLC. We read everything
and answer as we can, but we do not offer guaranteed response times on public
repositories. For paid support or consulting, see <https://www.ariesworx.com>.
